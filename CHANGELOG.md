# Changelog

## 1.0.0-rc.2

- **Your local workspace:** Take an idea through research, finding customers, and running experiments. Charlie can brief your connected coding tool to build a landing page or product, then watch the build and check the result. To start a build, connect your own tool in **Settings > Keys and connections > Coding tools**.
- **Coding tools:** Codex, Claude Code, Cursor and OpenCode can build on your subscription. OpenCode supports file reads and edits but does not run commands or fetch pages. Connect your tool in **Settings > Keys and connections > Coding tools**.
- **AI providers:** OpenAI, Azure OpenAI, Anthropic, OpenRouter, Ollama, LM Studio, and OpenAI-compatible endpoints. Connect yours in **Settings > Keys and connections > Your AI provider**.
- **Privacy:** Your services, SQLite database, and workspace files stay on your computer. Telemetry is off and GitHub update checks are opt-in. The providers and coding tools you choose still receive what they need for the work you request.
- **Platforms:** macOS tested; Linux tested headlessly, with the desktop UI unverified; Windows source setup is an unverified developer preview.
- **Known limitations:** Built-in customer search can return few results without a key. For broader coverage, choose and configure a search provider in **Settings > Keys and connections**.
