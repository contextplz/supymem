# Run Supymem on your laptop

Your desktop window, Python API, worker, Next.js interface, and SQLite workspace run on your machine with your keys and requested work.

## Start

Run `./start` on Mac or Linux, or `.\start.ps1` in Windows PowerShell. For the browser, add `--web` and open the printed loopback URL. See [installation](install.md) for automatic downloads and data locations. An installer contains Python and Node; this checkout is not proof of publication or clean-machine startup.

Choose your model or **Try without a key (sample mode)**. Built-in public-web search and reading need no key. Sample output is fictional, not market evidence.

## Build with your own tool

In **Settings > Keys and connections > Coding tools**, follow the [coding-tool setup and supported builds](../../README.md#build-with-your-own-coding-tool) using your own login.

Charlie decides when a build is the right next step and offers it. When you ask, Charlie writes the brief, starts your tool, watches it, checks the result and shows it. Your tool builds your landing pages, product, fixes and small tools on your laptop using your own subscription. Supymem does not write your code or switch to another builder.

Start with a static page or small local web app. Ask Charlie to split a larger product into smaller steps. Watch or stop work in **Build activity** and choose **Open result folder** in your desktop app. No connected tool means Charlie offers [coding-tool setup](keys.md#coding-tools). Nothing is published unless you ask.

## Your controls

**Keys and connections** saves your accounts. Data-folder `.env` import uses the same stores; app-saved fields win. **Settings > Capabilities**, titled **Your capabilities**, controls switches. Send email, Publish pages, and Connected apps start off. Saving credentials or enabling a switch starts no work.

Your request authorizes that work. Outreach keeps disclosure, opt-out, postal address, suppression, permission checks, and caps. Guessed emails stay off. Selected cloud services receive their requested inputs; built-in research also uses the network. Keep services private and read [the security model](SECURITY_MODEL.md) before remote configuration.
